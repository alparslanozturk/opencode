# lessons-learned/ — görev sonu önerileri

Ajan her görev sonunda işe yarar bir şey öğrendiyse buraya **öneri** yazar.
Bu bir emir değil, **öneridir**: onaylanana kadar davranışı değiştirmez.

- Dosya: `YYYY-MM-DD-kisa-ad.yaml` (şablon: `_TEMPLATE.yaml`)
- Alanlar: `task` · `problem` · `suggestion` · `confidence` (+ `evidence`, `skill_etkisi`)
- Terfi yolu: öneri olgunlaşırsa → `../skills/experimental/` → (onay) → `../skills/approved/`
- Haftalık özet: `../roadmap/reports/` (kaç vaka, kaç yeni beceri önerisi, kaç başarısız otomasyon)
