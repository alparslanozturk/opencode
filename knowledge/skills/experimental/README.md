# experimental/ — onay bekleyen beceriler

Buraya **üretilmiş ama henüz onaylanmamış**, denenmekte olan beceriler düşer.

- opencode bu dizini **OKUMAZ** (yalnız `../approved/` okunur) → buradaki içerik davranışı değiştirmez.
- Akış: `../generated/` (ham) → **burası** (deneniyor) → `../approved/` (onaylı, canlı)
- Biçim: `<ad>/SKILL.md` (frontmatter: `name`, `description`)

Onay: içeriği oku; beğenirsen `../approved/` altına taşı, beğenmezsen **sil**.
