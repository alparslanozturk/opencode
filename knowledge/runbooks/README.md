# runbooks/ — operasyon prosedürleri

Beceri = "ne zaman, nasıl davran" bilgisi (kısa, agent yükler).
Runbook = **uzun, sıralı, uçtan uca** operasyon prosedürü (çok sistem, kontrol noktaları, geri dönüş adımları).

| Nereye | Ne |
|---|---|
| `../skills/approved/` | Kısa usül / karar rehberi / tek konu |
| `runbooks/` | Uzun prosedür (insan okur-uygular; ajan da referans alabilir) |

- Şablon: `_TEMPLATE.md`
- Dosya adı: `konu-kisa-ad.md` (ör. `satellite-patch-haftasi.md`)
